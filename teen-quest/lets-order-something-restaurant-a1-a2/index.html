Mission 03 · Understand & practice

Language Focus

Countable nouns

Things you can count: one apple, two sandwiches, three eggs.

Use a/an with one: a burger, an apple.

Uncountable nouns

Things we don't usually count individually: water, rice, milk, bread.

Say some rice or a glass of water.

Some / Any

Some: “I'd like some water.”

Any: “Do you have any juice?” / “We don't have any.”

I'd like…

I'd like = I would like (Eu gostaria).

“I'd like a sandwich, please.”

“Could I have the bill, please?”

Notice: “Would you like some water?” is also natural. We often use some when offering something.

Mission 06 · Speak

Role-Play Challenge

Work with a partner. Switch roles after the first round.

👩‍🍳 Role A · Waiter

Greet the customer, offer a table, give the menu, ask about the order, check if everything is okay, and bring the bill.

🧑 Role B · Customer

Ask for a table, ask about a dish, order food and a drink, ask for a change, and request the bill.

Useful phrases: “A table for two, please.” · “What do you recommend?” · “I'd like…” · “Do you have any…?” · “Could we have the bill?”
